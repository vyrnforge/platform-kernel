## Baseline and scope

- Published immutable baseline: [v0.3.2](https://github.com/vyrnforge/platform-kernel/releases/tag/v0.3.2), source `c86eb33a46fae2843c75181c6b395cd0dc6710fe`.
- Approved and tested KDX source: protected `main` `fcc6d7623b8475c8ce6ec450676d454b5a3ecbfe` / Git tree `16f4de6d600d76d81d9b9008713284911d9ea615`, with PRs [#55–#63](https://github.com/vyrnforge/platform-kernel/issues/54) merged.
- Version decision: **0.4.0 (pre-1.0 MINOR)** rather than a patch because an additive public tenantless factory and optional JDBC JSON mapper constructor expand the Java API. This is not a claim of a stable 1.0 semantic-compatibility guarantee. The two stricter input validators are behavior changes for invalid inputs and require upgrade checks.
- Maven coordinates: `io.github.vyrnforge:{platform-kernel,platform-kernel-jdbc,platform-kernel-testkit}:0.4.0`; test-only Asset reference and parent versions align but are **not** extra published libraries.
- Java floor 21 unchanged. Core has no production third-party dependencies. Optional JDBC retains its existing Flyway/Jackson/PostgreSQL dependencies. Testkit remains test-only; no new mandatory runtime.
- Released v0.2 wire JSON schemas and frozen historical v0.1 baselines unchanged; Flyway V1–V3 bytes/versions unchanged. No new schema migration or new runtime service.
